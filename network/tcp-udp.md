# TCP-UDP

## 내가 공부 전 아는 상식
* TCP와 UDP는 모두 데이터 전송계층에 속하며, TCP는 신뢰성이 있고, UDP는 없다.
* TCP는 비교적 작은 용량을 전송하고 UDP는 대용량 전송에 효율적이다.
* UDP는 사진이나 영상을 전송한다.

 ## 핵심 차이
| | TCP | UDP |
|---|---|---|
| 연결 방식 | 연결 지향 (3-way handshake) | 비연결 |
| 신뢰성 | 보장 (재전송) | 보장 안 함 |
| 순서 보장 | O | X |
| 속도 | 느림 | 빠름 |

## 3-way handshake
클라이언트 → 서버: SYN
서버 → 클라이언트: SYN-ACK
클라이언트 → 서버: ACK
이후 데이터 전송

## 사용 사례
- TCP: HTTP/HTTPS, 파일 전송, 이메일 (데이터 정확성이 중요)
- UDP: DNS, 영상 스트리밍, 온라인 게임 (속도가 중요, 일부 손실 허용)

## 프로젝트 적용
- FastAPI는 HTTP 기반 → TCP 위에서 동작
- 팡팡팡 EC2 서버 통신도 모두 TCP
