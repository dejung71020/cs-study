# OSI 7계층

## 내가 공부 전 아는 상식
* 7계층이 있고 물리, 데이터링크, 네트워크, 전송, 세션, 표현, 응용 계층이 있다.
* 전송계층이 TCP, UDP가 있다.
* IP, ARP, RARP가 네트워크 계층이다.
* 물리가 리피터, 데이터링크가 스위치, 네트워크가 라우터다.

## 7계층 구조

| 계층 | 이름 | 역할 | 프로토콜/장비 |
|---|---|---|---|
| 7 | 응용 (Application) | 사용자 인터페이스 | HTTP, FTP, DNS, SMTP |
| 6 | 표현 (Presentation) | 데이터 변환, 암호화, 압축 | SSL/TLS, JPEG, JSON |
| 5 | 세션 (Session) | 연결 수립·유지·종료 | NetBIOS, RPC |
| 4 | 전송 (Transport) | 신뢰성 있는 데이터 전송 | TCP, UDP |
| 3 | 네트워크 (Network) | IP 주소 기반 라우팅 | IP, ICMP, 라우터 |
| 2 | 데이터링크 (Data Link) | MAC 주소, 에러 감지 | Ethernet, 스위치 |
| 1 | 물리 (Physical) | 비트 전송 (전기 신호) | 케이블, 허브 |

## TCP/IP 4계층과 비교

| TCP/IP 4계층 | OSI 7계층 |
|---|---|
| 응용 계층 | 응용 + 표현 + 세션 (5~7) |
| 전송 계층 | 전송 (4) |
| 인터넷 계층 | 네트워크 (3) |
| 네트워크 인터페이스 | 데이터링크 + 물리 (1~2) |

실무에서는 TCP/IP 4계층을 더 많이 사용하고, OSI 7계층은 개념 이해용으로 쓰인다.

## 캡슐화 / 역캡슐화
- **송신 (캡슐화):** 7→1, 각 계층이 헤더를 붙여서 아래로 전달
- **수신 (역캡슐화):** 1→7, 각 계층이 헤더를 제거하며 위로 전달

## 면접 한 줄 답변
> "OSI 7계층은 네트워크 통신을 7단계로 나눠 각 계층의 역할을 명확히 한 모델입니다. 실제 구현은 TCP/IP 4계층을 따르며, HTTP는 응용 계층, TCP/UDP는 전송 계층에 해당합니다."

## 프로젝트 적용
- 팡팡팡 FastAPI: HTTP 요청이 7(HTTP) → 4(TCP) → 3(IP) 순으로 내려가 EC2에 도달
- nginx + HTTPS: 6계층(TLS)에서 암호화 처리 후 전달
