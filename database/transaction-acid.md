# 트랜잭션과 ACID

## 트랜잭션이란

여러 쿼리를 하나의 작업 단위로 묶은 것.
전부 성공하거나, 하나라도 실패하면 전부 롤백.

## ACID

| 속성 | 설명 | 예시 |
|---|---|---|
| **Atomicity (원자성)** | 전부 성공 or 전부 실패 | 송금: 출금+입금 둘 다 성공해야 함 |
| **Consistency (일관성)** | 트랜잭션 전후 데이터 규칙 유지 | 잔액이 음수가 되면 안 됨 |
| **Isolation (격리성)** | 동시 트랜잭션이 서로 영향 안 줌 | A가 수정 중인 데이터를 B가 못 읽음 |
| **Durability (지속성)** | 커밋된 데이터는 영구 저장 | 서버 꺼져도 커밋된 데이터 유지 |

## SQLAlchemy에서 사용

```python
async with db.begin():  # 트랜잭션 시작
    await db.execute(update_stock)
    await db.execute(create_order)
# 여기서 자동 커밋, 예외 발생 시 자동 롤백
```
